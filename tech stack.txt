# InvestWall Technical Stack Document

## AI-Driven Detection of Synthetic Media & Phishing Attacks for Retail Investors

Version: 1.0

Platform: Android

---

# 1. Technology Philosophy

InvestWall is designed as a **modular AI pipeline** rather than a single AI model.

Each type of content (text, image, video, audio, document) is processed by a specialized detection engine that performs best for that modality. Their outputs are combined into a unified Evidence Fusion Layer, which produces a Trust Score and an explainable report.

This architecture provides:

* Higher detection accuracy
* Faster processing
* Easier maintenance
* Independent model upgrades
* Explainable decision making

# 10. LLM Layer

Purpose

Explain evidence—not perform detection.

The LLM receives structured outputs from every detection engine.

Example input

```
Image Score: 92

Video Score: 18

Audio Score: 7

Phishing Score: 85

Metadata Score: 40

Sender Reputation: Low
```

The LLM converts this into a user-friendly explanation.

Example output

> "This message is considered high risk because the attached image shows signs of AI generation, the sender domain has low reputation, and the text contains common phishing patterns encouraging immediate financial action."

Recommended models

* Gemma 3
* Qwen 3
* Llama 3.2 Instruct

Small instruction-tuned models are sufficient because reasoning is based on structured evidence rather than raw content.

---

# 11. Evidence Fusion Layer

Purpose

Combine outputs from all detection engines.

Inputs

* Text score
* Image score
* Video score
* Audio score
* Metadata score
* Authenticity score
* Domain reputation
* Phishing score

Processing

Weighted aggregation followed by calibrated confidence estimation.

Outputs

* Trust Score
* Confidence
* Primary threat category
* Evidence summary

This layer acts as the decision engine before the explanation model.

# 15. Why This Stack

Every technology is chosen because it is mature, actively maintained, and purpose-built for its role:

* Kotlin and Jetpack Compose provide a modern native Android experience.
* FastAPI offers high-performance asynchronous APIs for AI inference.
* Specialized multimodal models outperform a single general-purpose detector.
* The Evidence Fusion Layer produces more reliable decisions by combining independent signals.
* The LLM focuses on explainability rather than classification, improving transparency and user trust.
* A modular architecture allows any detection engine to be upgraded independently as new research emerges without redesigning the entire system.
